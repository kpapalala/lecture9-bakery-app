Bakery Tracker · Simple version

This is a standalone copy of the simple bakery tracker. It includes the order CSV and seven Instagram message files needed to run on another computer.

Start it

  1. Open Terminal in this folder.
  2. Run python3 app.py (Windows: python app.py).
  3. Open http://127.0.0.1:8001.

Keep Terminal open. Press Ctrl+C to stop the app.

Use it

  1. Click Get Monday’s messages. New orders with less than two days’ notice or too little oven capacity are rejected automatically. Other valid new orders wait for your decision.
  2. Accept or reject each requested order. Changes and cancellations are checked and applied when that day’s messages load.
  3. Book a helper for a future pickup day if more oven time is needed. A helper adds four hours and costs $100.
  4. Use Accept remaining and go to next day to finish the day. The app checks each remaining order in order and marks that day’s accepted orders as picked up. It asks you to confirm first.
  5. Use Undo last action if you need to reverse a decision, helper booking, message load, or day change.

What the numbers mean

Scheduled sales includes accepted and picked-up orders. Sales after helper costs subtracts $100 for each booked helper day. Daily oven time includes accepted and picked-up orders; requested and rejected orders do not reserve capacity.

Files and implementation

app.py contains the server, rules, and page. bakery.db stores orders, messages, helper bookings, the current day, and undo history. On first launch, it imports existing orders from existing_orders.csv. Each day’s Instagram HTML file is read when you click the message button. The app uses Python’s standard library and makes no AI or Instagram network calls.
